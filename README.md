# Disconnected Content for Cockpit: interactive demo

This branch hosts the GitHub Pages demo at
https://estuart.github.io/cockpit-disconnected-content/

`index.html` is a self-contained, offline simulation of the plugin. The real
plugin frontend from `main` runs against an in-browser simulated backend, with
a guided tour and a 3D view of the air-gap workflow. No servers are involved.

**Controls:** `→` or `PageDown` does the highlighted step (or click the UI
yourself), `←` goes back, `F` expands the 3D view, `G` hides the guide, `D`
toggles dark mode, and `Shift+R` restarts.

The plugin source and install instructions are on the `main` branch.
